# La chiave di Venezia — tutto il testo (livello 1)

## Lezione 1 — L'ufficio vuoto

1. È un tavolo. È una sedia.
2. È un libro. È una penna.
3. È un libro…
4. È una penna. «C. Rossi».
5. Continua…

**Domande**

- È un tavolo o una sedia? → *È una sedia.*
- È un libro? → *Sì, è un libro.*
- Che cos'è? → *È una penna.*
